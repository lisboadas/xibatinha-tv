# Xibatinha TV

Player IPTV moderno para Windows, com várias listas, perfis, EPG e troca rápida de canais.

## Baixar

Baixe o instalador mais recente na aba **Releases** (`Xibatinha-TV-Setup-*.exe`) e execute. O app avisa sozinho quando houver uma versão nova.

O Windows pode mostrar o aviso do SmartScreen porque o instalador não é assinado: clique em **Mais informações** e depois em **Executar assim mesmo**.
